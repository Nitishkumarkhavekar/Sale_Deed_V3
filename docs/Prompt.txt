## User Workflow

Upload all PDFs (prompt the user for username and batch name. Date/time should be taken automatically, number of files should be detected automatically.   `saledeed main\refering docs\example.csv`)

Each Stage (Batch-wise)

Within the batch, if any process fails:

- OCR will be tried only once.
- LLM checks confidence and tries once again.
- Refer:
  `saledeed main\refering docs\INFERENCE_PIPELINE.md`

If any stage fails, mark that `document_id` as failed in that batch.
If passed, mark it as processed.

OCR:
- Each PDF → Images → OCRed (Surya OCR) → Saved to DB (File name and address only, no images).

Extract:
- Each OCR → LLM Extract → Data validation and verification.
- Cross-verify with OCR.
- Apply regex on registration fee and match.
- Retry one last time if not satisfied, too much missing data, wrong data, or low confidence.
- Save to DB.

Translate:
- Each structured data.
- Only Kannada values will be translated using IndicTrans.
- Names will be transliterated, and one mapping will be used to achieve something like Kannada "EN" → "N", etc.
- Addresses will be directly translated using IndicTrans, which is faster.

Save to DB & Clear Batch:
- Delete PDF files from storage after batch completion.
- Check that whole data is continuously committed to the DB for the full batch during the entire process.

### Validation Rules



This page should list all validation rules with a toggle button.

- PAN verification method:
  When LLM replies with parties and PANs, check how many matched.
  Then in remarks (42-column person details remarks), add code "PM" in the respective row.
  If LLM extracts a PAN that is not present, discard it.
  (Be careful: PAN can be written with any enclosures or spaces.)
  If OCR has more PANs, list all in remarks (15th column remarks).

- Registration fee:
  Match it with OCR.
  It should not be more than Sale Consideration.
  If greater, use code "SSV".
  If registration fee does not match OCR, use code "WSV".
  (Check OCR example; it is mentioned as Registration Fee or Nondani Shulk. In output, rename it as Stamp Value.)
  (Use codes in the 42-column remarks.)

- Check and match Sale Consideration with OCR.
  (Has Indian numbering.)
  Use code "WSC". (42-column)

- Check Aadhaar numbers with OCR.
  If they don't match (may contain enclosures and spaces), use code "WAN". (42-column)

- Check Transaction Date from OCR.
  If not found, use code "WTD".
