Website UI Design (Figma)

Design System

- Theme: UX4G Design System (Government of India)
- Layout: Left Navigation + Right Content Area
- Framework Style: Modern Government Portal
- Responsive Layout
- Rounded Cards (12px)
- Buttons Radius: 8px
- Typography: Noto Sans / Inter
- Icons: Material Symbols
- Primary Color: Government Green
- Secondary Color: India Saffron
- Accent Color: Blue
- Background: Light Gray (#F7F9FC)
- White Cards with Soft Shadow
